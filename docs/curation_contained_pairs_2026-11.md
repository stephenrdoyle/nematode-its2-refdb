# Within-genus contained pairs in nemits2 v0.2.3: curation screen (2026-11)

This screen covers v0.2.3's `taxonomy.tsv` `contained_in` / `contains` links between named records of two species in one genus. There are 146 record links across 53 species pairs. Each pair was screened for curation errors of the kind found in the five cross-genus pairs in v0.2.3 (`curation/overrides.tsv`, rows dated 2026-11-15).

**Policy:** `relabel` is used only for published synonyms. `drop` is for records that are likely misidentified, so no accession carries a name GenBank does not. `leave` is for ITS2 that is genuinely shared between species.

**Evidence per pair:**
- Records and accessions per species (`members.tsv`, kept rows).
- For each flagged record, `own`: the edits to the nearest other record of its own species (`bin/build.py` `span_distance`). The species' median nearest-own distance is its "spread".
- `rest A→B / A→restB`: the closest the two species come once the flagged records are set aside. A value of 1-2 means the two species are close everywhere, not just in this record.
- `results/curation/species_coherence.tsv` calls (`displaced`, `closer`).
- GenBank metadata (study, isolate, host, country).
- NCBI Taxonomy, queried 2026-11-15: all 88 names are separate species there, with none merged as synonyms.
- Literature.

GenBank names: every flagged accession carries the species name shown, except some *Anisakis simplex* accessions, which GenBank names "Anisakis simplex sensu lato".

## Decision (2026-11-15)

- the three relabels (rows 12, 32, 33);

Each is a separate PR.
